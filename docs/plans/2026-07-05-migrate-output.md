# `--migrate` T-SQL Output Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a `--migrate` flag and an `emitMigration(result, opts)` renderer that turns a DBML diff into a T-SQL migration script (CREATE/ALTER DDL), with destructive and heuristic statements commented out for safety.

**Architecture:** A new pure renderer in `lib/emit.js` (`DiffResult -> string`), mirroring `emitDbml`/`emitText`/`emitJson`. No new parsing or diffing - it walks the existing diff result. Exported from `lib/index.js` (programmatic API) and wired into `bin/dbml-diff.js` as a `--migrate` flag mutually exclusive with `--format`, honoring `-o/--output`.

**Tech Stack:** Node.js, Jest (snapshot + targeted assertions). T-SQL dialect only.

**Design doc:** `docs/plans/2026-07-05-migrate-output-design.md`

**Working dir:** worktree at `.worktrees/18-migrate` on branch `feature/18-migrate-output`. Run all commands from there.

**Fixture facts (from `__tests__/fixtures/v1.dbml -> v2.dbml`, counts added:1 removed:1 modified:4):**
- Added table: `dbo.PlanKind` (Id INT NOT NULL pk, Title NVARCHAR(100) NOT NULL, Sku NVARCHAR(50) NOT NULL).
- Removed table: `dbo.LegacyLog`.
- `dbo.Subscriptions`: adds `PlanKindId INT NOT NULL`; `EnrolledOn` NOT NULL -> nullable.

Column shape: `{ name, type, notNull, pk, note }`. ModifiedTable: `{ name, columns, columnsAdded, columnsRemoved, columnsChanged: [{column, changes}], renames: [{from, to}] }`. TableEntry (added/removed): `{ name, columns }`.

```js
/** Quote a fully-qualified T-SQL name: `sales.orders` -> `[sales].[orders]`. */
const qname = (name) => name.split('.').map((p) => `[${p}]`).join('.');
/** Quote a bare identifier: `col` -> `[col]`. */
const qid = (id) => `[${id}]`;
/** Render a column's type + nullability for DDL. */
const colType = (c) => `${c.type} ${c.notNull ? 'NOT NULL' : 'NULL'}`;

/**
 * Render a diff result as a T-SQL migration script. Destructive (DROP) and
 * heuristic (rename) statements are emitted commented out.
 * @param {DiffResult} result
 * @param {Object} [opts]
 * @param {string} [opts.oldLabel='old']
 * @param {string} [opts.newLabel='new']
 * @param {Date|string} [opts.date] Defaults to today.
 * @returns {string} T-SQL source
 */
function emitMigration(result, opts = {}) {
  const oldLabel = opts.oldLabel || 'old';
  const newLabel = opts.newLabel || 'new';
  const stamp = (opts.date ? new Date(opts.date) : new Date()).toISOString().slice(0, 10);
  const { added, removed, modified } = result.tables;
  if (!added.length && !removed.length && !modified.length) return '-- No schema changes.';

  const L = [];
  L.push(
    `-- Schema migration: ${oldLabel} -> ${newLabel}`,
    `-- Generated by dbml-diff on ${stamp}`,
    `-- Dialect: T-SQL (SQL Server / Synapse)`,
    `-- WARNING: destructive (DROP) and heuristic (RENAME) statements are commented`,
    `--          out below. Review and uncomment deliberately.`,
    `-- Enums and TableGroups are not represented in SQL.`,
    ``
  );

  for (const t of added) {
    L.push(`-- === table ${qname(t.name)} (added) ===`);
    const lines = t.columns.map((c) => `  ${qid(c.name)} ${colType(c)}`);
    const pks = t.columns.filter((c) => c.pk).map((c) => qid(c.name));
    if (pks.length) {
      const bare = t.name.split('.').pop();
      lines.push(`  CONSTRAINT ${qid(`PK_${bare}`)} PRIMARY KEY (${pks.join(', ')})`);
    }
    L.push(`CREATE TABLE ${qname(t.name)} (`, lines.join(',\n'), `);`, ``);
  }

  return L.join('\n').replace(/\n+$/, '');
}
```
